For MFQ policies, I added the scheduling rules in scheduler(), the new process rules in allocproc, and a one line reset in userinit(). The scheduler checks for runnables in q0 before q1 and before q2 each time it schedules a process. Used processes get demoted.
Boosting is called in every case after process switch which checks for wait times in q2 above 50. 
The first test program runs two processes: one on a high cpu workload, and one a io workload.
The second test runs 7 threads: 1 parent, which forks into 5 children, each doing an io workload. Every thread calls getpinfo at the end
The third test runs 2 threads: 1 in a sleep loop, another waiting. The sleep thread calls getpinfo at the end.
